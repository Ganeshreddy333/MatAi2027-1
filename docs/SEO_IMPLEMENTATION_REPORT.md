# MatAi 2027 technical SEO audit and implementation

**Scope:** source audit and local changes only. No production deployment, Google Search Console access, PageSpeed run, or ranking guarantee is claimed.

## Audit findings

Live checks performed before changes on 2026-11-12:

- `https://matai2027.com/`, `https://www.matai2027.com/`, and `/index.html` all returned HTTP 200 without a redirect from the tested HTTPS variants. The `www` host and `index.html` therefore exposed duplicate URL variants.
- `http://matai2027.com/` redirected to HTTPS, but the tested HTTP `www` URL remained on the `www` host after its scheme upgrade.
- `/robots.txt` and `/sitemap.xml` both returned 404.
- Important HTML pages already had distinct titles and descriptions and one H1 each. They did not define canonical or Open Graph/Twitter metadata. The admin and custom error pages already had `noindex,nofollow`.
- The homepage contained the visible conference dates and Berlin location, but no structured event data. The specific venue is still unannounced, so no venue name or street address is asserted.
- The shared navigation is generated by JavaScript. Main page content and many body links are regular HTML; Google rendering should still be checked in Search Console.
- No individual public speaker/committee URLs are backed by public database records. The database contains editable site content and private submissions, not public URL entities. Registration, payment, and participant rows must never be added to a public sitemap.
- Similar sponsor pages were retained as separate canonical URLs: a content-text overlap check found they are related but not identical. Their distinct content and route usage should be reviewed in Search Console after indexing.
- The homepage hero fallback image is 770×335 and about 668 KB; one venue image is about 2 MB. No field Core Web Vitals data was available.

## Changes implemented

### Crawlability, URLs, and sitemap

- Root [`.htaccess`](../.htaccess) and [`frontend/.htaccess`](../frontend/.htaccess) permanently redirect HTTP and non-canonical hosts to `https://matai2027.com`; `/index.html` redirects to `/`. Existing `.html` paths remain unchanged.
- [`frontend/robots.txt`](../frontend/robots.txt) allows public resources, discourages crawling admin/API/upload paths, and declares the sitemap. Robots rules are not an access-control mechanism; server authentication remains required.
- [`backend/src/Seo.php`](../backend/src/Seo.php) produces XML for `/sitemap.xml` from an explicit allowlist of public HTML pages. It excludes the admin, API, upload, error, and private-record routes, escapes XML, and omits `lastmod` because reliable per-page content modification timestamps are not available.
- [`frontend/api.php`](../frontend/api.php) serves the sitemap before constructing the application/database connection, so a database outage cannot corrupt sitemap XML. [`backend/php/router.php`](../backend/php/router.php) and the Apache rewrite rules route the endpoint in supported deployment modes.
- The sitemap is intentionally generated from the actual public page catalog, not the database: there are no public database-backed page URLs to enumerate safely.

### Metadata and structured data

- All 14 indexable HTML pages now have absolute HTTPS canonicals, page-specific Open Graph title/description/URL, and Twitter card/title/description. Existing `.html` URLs are preserved; the homepage canonical is `/`.
- Admin and error pages already have `noindex,nofollow`; no change was necessary.
- The homepage includes JSON-LD `WebSite` and `Event` entities using the visible event name, dates, and Berlin location. Attendance mode, organizer identity, ticket offers, specific venue, speakers, and affiliations are omitted because the website does not confirm them.

### Performance

- The homepage preloads its existing CSS background hero image with high fetch priority. This may improve discovery of the likely LCP asset, but no LCP/INP/CLS improvement is asserted without field or lab measurements.
- No image paths, registration pricing, payment logic, database schema, or content records were changed.

Next content work should prioritize confirmed session topics, real speaker/committee biographies, final venue details, and dated submission deadlines. Avoid publishing placeholder profiles or invented affiliations. Build authority through genuine university, association, and research-network listings only.

## Database and security

- No schema or data changes were made.
- The sitemap contains only explicit public page paths; it does not query or expose submission data.
- Admin/API crawling exclusions are supplementary only. Admin API authentication and existing server-side controls remain the security boundary.
- XML is escaped using `ENT_XML1`; page metadata is static and contains no user-generated values.

- Live baseline status checks listed above; these describe the site before deployment of these changes.

Not verified in this environment:

- PHP lint/PHPUnit, because PHP is unavailable locally.
- Apache/LiteSpeed `.htaccess` rewrite behavior, sitemap XML over the deployed PHP handler, redirects after deployment, or per-URL production status. A local `apachectl -t` passed, but does not validate these `.htaccess` rules.

- Mobile rendering, broken-image crawling, real/lab Core Web Vitals, PHP/MySQL health, Search Console indexing/canonical selection, or live payment flows.
- Competitor ranking, keyword volume, or difficulty. Google search result fetches were not reliably extractable in this environment.
